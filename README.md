# DocFlow

DocFlow is a document processing platform built with Spring Boot.

## Planned Features

- Document conversion (DOCX, ODT, PDF, HTML, RTF)
- PDF merge and split
- Watermarks
- Metadata extraction
- OCR
- Batch processing
- Document pipelines
- REST API
- OpenAPI documentation

## Technology Stack

- Java 21
- Spring Boot
- Gradle
- Lombok
- Spring REST Docs
